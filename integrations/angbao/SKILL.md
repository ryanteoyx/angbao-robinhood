Use an existing working installation or explicitly chosen hosted connection for the request without reinstalling. The new-local-install checks below do not require a local runtime for an existing native hosted connection.

## Continue saved work in another agent

Local use stays signup-free. A second trusted agent on the same computer can use the same running Angbao workspace. For a chosen review or brief, call `angbao_read_handoff` with `{kind:"review"|"research-brief",recordId}` or `angbao agent handoff --review ID` / `--brief ID`. The GUI's **Copy for another agent** button provides the exact reference without copying financial figures or credentials. In the receiving agent, resolve that reference with its own existing connection, including `workspaceId`, `digest` and `baseETag`. Never silently choose the latest record or switch workspaces. A claimed client name is not verified harness identity.

Explain current changes first. A review handoff contains the immutable original inputs, exact strategy/version/settings, current inputs and saved decision/feedback. `currentInstalledStrategy` may differ; repeating uses the **saved review settings**, preserving current installed preferences. Confirm current inputs, then use `agent repeat` with the original review ID and a deliberate new operation identity. A missing goal, changed input type/currency or incomplete snapshot requires resolution rather than guessed defaults. Research handoffs retain sources, claims, gaps, predecessor and baseline references. Unavailable references stay unavailable; inspect an existing newer version before authoring. Use `continuation.authoringDraft` as the editable authoring payload; it removes server-owned metadata without dropping sources or gaps. Save only final synthesis through the normal preview/confirmation flow, retaining `previousVersionId` and the selected `baselineId`.

A handoff is read-only and grants no access. Hosted continuation requires the recipient's separate, unexpired grant: review continuation reads require both history and workspace scopes; research-only continuation requires only research read. Revoke each connection independently. No hosted context-write, provider, spending or financial rights are added. An uncertain save made by another agent is **inspect-only**: don't replace its key and repeat it. Original-agent exact replay remains grant-scoped. Local clients share one trusted loopback workspace and are not isolated from each other. This feature is same-workspace continuation, not cross-installation synchronization.
