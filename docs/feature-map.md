# Complete feature map

[← Angbao](../README.md) · [Product overview](product-overview.md) · [Architecture](architecture.md) · [Business strategy](business-strategy.md) · [Evidence](submission-evidence.md)

This preserves **all 57 feature families** in the product direction as of 25 October 2026. It is a scope map, not a list of 57 completed features. The accepted submission is the 0.5.11 local review/continuity workflow, one approved Elfa evidence slice and a separately approved Robinhood Chain Testnet decision checkpoint.

**How to read it:** “working slice” means only the stated behavior is accepted. “Foundations” means source exists without a launched end-to-end service. “Planned” means do not expect that capability in the current installer. There is no implied delivery date or entitlement. [Exact evidence and limits](submission-evidence.md).

## Delivery sequence

1. Keep the free single-person install → useful review → save → return/export loop reliable.
2. Add independent harness/client acceptance and better authorized portfolio/source inputs.
3. Deliver two-owner hosted continuity and one bounded durable duty before selling the corresponding managed service.
4. Add execution-enforced revocable permissions on the supported chain/account path before delegated financial action.
5. Add independent method publication/install, collaboration and qualified feedback before creator commerce, leaderboards or reputation.

These are dependency gates, not a reason to hide the broader product vision. Research, memory and orchestration remain offchain. The wallet/chain path is optional and separately authorized.

## Product rules that apply across the map

- **Free first:** local tools, owned context, basic persistence, supported manual methods, inspection, export and essential recovery do not require a subscription.
- **Account later:** sign in when choosing an available hosted benefit, with a clear upload destination and a way to decline. Account creation is not wallet permission.
- **Payment for maintained value:** proposed sync/continuity and bounded background duties must operate before being sold. Pricing is a hypothesis; provider/model/gas resources are separate.
- **No invented account truth:** dates, source, coverage and instrument identity matter. Missing data remains a gap; a plausible article does not create a position or order.
- **Own the business record:** exact financial context, method/policy versions and outcomes remain portable. Hidden model reasoning and credentials are not portable memory.
- **One-person/multi-agent is different from multiplayer:** several assistants working for one owner do not prove two-person publishing, licensing, reputation or independent network effects.
- **Chain evidence has a precise meaning:** a commitment records a fingerprint; it does not establish research truth, returns, ZK verification or a spending mandate.

For each family, the next useful question is what accepted user outcome its implementation enables. Source-module count, connected accounts, credits, test counts and a successful submission are not substitutes for that outcome.
